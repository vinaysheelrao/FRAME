# Security

This is a small personal-use project; no response-time or security guarantee is
offered. Run a current browser and use releases from a repository you trust.

For a vulnerability, use the repository's **Security → Report a vulnerability**
private channel if the maintainer has enabled it. Do not publish credentials,
personal paths, backups, or an exploit that exposes users' data in a public issue.
If the private channel is absent, open a minimal issue asking for a private
contact method, without exploit details or personal information.

Include the release, browser/OS versions, affected flow and a minimal reproduction
using synthetic data. The maintainer should enable private vulnerability reporting
before public distribution. No private contact address has been invented here.

Credentials are local client-side data, not protected server secrets. Imported
backups may cause requests to referenced HTTPS image hosts. The browser's file
permission boundary and codec support remain in force. No native helper runs.
