# Changelog

## 0.1.0 — 2026-10-17

Initial repository bundle of FRAME with folder scanning, automatic metadata
matching, grouped series, local playback/resume, subtitles, watchlists, cast
portraits, source path copying and library backup/import.

Public distribution preparation removes reference-page posters, adds complete
embedded licensing/privacy notices and the approved TMDB attribution logo,
preserves provider attribution after manual edits and imports, expires TMDB
cache after 150 days, and omits TMDB-derived content from new exports.

Known limits: browser codec support, folder reconnection, fallback picker start
folders, no native desktop-player launch, and no background work while closed.
